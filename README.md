This repository contains the source code for the official website of Vyxen Ledger, a premium accounting and financial advisory firm. The platform is designed to offer specialized mentoring, consulting, and training services for entrepreneurs and MSMEs (Micro, Small, and Medium-sized Enterprises).

The site transforms traditional accounting concepts into practical, clear, and innovative tools to help businesses achieve financial stability and growth.

## Features

*   **Comprehensive Service Showcase**: Detailed sections for all services offered:
    *   Accounting Mentoring
    *   Practical Workshops
    *   Legal & Tax Formalization
    *   Inventory Control
    *   Real Cost Calculation
    *   Strategic Pricing
*   **Modern & Responsive Design**: A professional, dark-themed UI with gold accents, fully responsive for an optimal experience on desktops, tablets, and mobile devices.
*   **Interactive Elements**:
    *   Smooth scroll-reveal animations for a dynamic user experience.
    *   An interactive FAQ section built with native HTML elements.
    *   A functional contact form with client-side validation and success notifications.
*   **Lead Generation Tools**: A "Free Resources" section offering downloadable templates to attract and engage potential clients.
*   **Pure Frontend**: Built with clean, vanilla HTML, CSS, and JavaScript, ensuring fast load times and no complex dependencies.

## Technology Stack

*   **HTML5**: For the core structure and content of the website.
*   **CSS3**: For all styling, layout, and responsive design using media queries.
*   **Vanilla JavaScript**: For DOM manipulation, event handling, and interactive features like the mobile menu and scroll animations.

## Getting Started

To view or work on the project locally, follow these steps:

1.  Clone the repository to your local machine:
    ```sh
    git clone https://github.com/RussellMurft/Vyxen_Ledger.git
    ```

2.  Navigate into the project directory:
    ```sh
    cd Vyxen_Ledger/Vyxen_Ledger
    ```

3.  Open the `index.html` file in your preferred web browser. No local server or build process is required.
